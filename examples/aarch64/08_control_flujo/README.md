# 08 · Control De Flujo Y Programacion Estructurada

Bloque: Programas Linux.

Esta unidad traduce decisiones y repeticion a etiquetas, ramas, condiciones,
loops, branches especializados, `csel`, `bl` y `ret`.

## Ejemplos

| Ejemplo | Leccion | Estado |
|---|---|---|
| `01_branching_etiquetas` | 08.1 · Branching y etiquetas | implementado |
| `02_condiciones_flags` | 08.2 · Condiciones y flags | implementado |
| `03_if_else` | 08.3 · if/else | implementado |
| `04_loops_recorrido` | 08.4 · Loops y recorrido | implementado |
| `05_csel_branches` | 08.5 · Branches especializados y csel | implementado |

## Flujo Recomendado

1. Empieza con saltos directos y etiquetas.
2. Compara condiciones signed y unsigned.
3. Traduce un `if/else` completo.
4. Recorre un array con un loop real.
5. Usa branches especializados para casos frecuentes.
6. Termina con `bl` y `ret` como preparacion para funciones.
