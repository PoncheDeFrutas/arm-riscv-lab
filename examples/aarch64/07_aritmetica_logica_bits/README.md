# 07 · Aritmetica, Logica, Flags Y Bits

Bloque: Programas Linux.

Esta unidad practica constantes, aritmetica con flags, multiplicacion/division,
mascaras, shifts, extensiones y campos de bits.

## Flujo Recomendado

1. Construye constantes antes de combinarlas con operaciones.
2. Revisa que instrucciones actualizan flags y cuales no.
3. Usa multiplicacion/division con valores pequenos.
4. Practica mascaras antes de shifts y bitfields.
5. Cierra con la lectura guiada para explicar un flujo completo.
