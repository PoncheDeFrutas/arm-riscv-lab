# 01 · Laboratorio ARM64 Reproducible

Bloque: Fundamentos.

Esta unidad fija el flujo de trabajo: compilar, ejecutar, inspeccionar y depurar
programas AArch64 pequeños.

| Ejemplo | Leccion | Estado |
|---|---|---|

make -f Makefile.qemu EXAMPLE=01_laboratorio/03_primer_programa run
